# GameDay Crew

GameDay Crew is a junior Australian Rules football team-management app for clubs, coordinators, team managers and helpers.

## Version 2 Development

This branch contains the development version of the new GameDay Crew platform.

### Goals

- Mobile-first for iPhone and Android
- Fully usable on desktop
- Installable as a Progressive Web App (PWA)
- Individual user accounts and secure login
- Club and team management
- Role-based access for Club Admins, Team Managers and Team Helpers
- Cloud-saved team and game data
- Game-day scoring
- Optional interchange tracking
- Awards tracking
- Career game milestones
- Player statistics and profiles
- PDF season reports and exports
- Historical season archives
- Push notification support
